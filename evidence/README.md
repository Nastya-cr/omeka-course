# Материалы проверки стенда

`configuration-check.txt` содержит фактический вывод проверки структуры YAML и скриптов в среде подготовки. Для проверки резервного копирования использован тестовый SQL-ответ без запуска MariaDB. Этот вывод не подтверждает развёртывание контейнеров.

Повторить проверку можно командой `python3 evidence/check_configuration.py` из папки `practice` в окружении с PyYAML, tar и sha256sum.

После запуска сохрани свои результаты, например:

- `01-compose.png` — пять запущенных сервисов из docker compose ps.
- `02-catalog.png` — поиск по названию и две коллекции.
- `03-document.png` — карточка с метаданными и открытым PDF.
- `04-swarm.png` — docker node ls и docker stack services library.
- `05-actions.png` — запуск CI/CD со статусами заданий.
- `06-restore.png` — та же карточка из отдельного восстановленного стенда.

Вставь результаты в подразделы 3.3–3.7 отчёта и на слайд 7. В протоколе приложения Б укажи, что получилось на самом деле. Результаты логов и скриншоты снимай без паролей, токенов и персональных данных.
